# ACBS training video transcripts (extended)

Prepared: 02/09/2026, Sticky CTA added 03/09/2026. Eighteen extended transcripts (2 to 3 minutes
each) for videos showing the Golden Rise team how to build pages with the ACF Components Block
System (ACBS) plugin. Written for a WordPress-comfortable, non-developer editor, except the last
video, which is for our own dev team.

This is the fuller, more explanatory version of each transcript. A tightened, scaled-back set
(row layouts at 0:30 to 1:30) lives in the plugin's own `docs/training-transcripts/` and is the
one to record from day to day; this set is kept for reference.

Each transcript is a self-contained script: a brief summary of its scope at the top, then the
spoken script with light `[ON SCREEN: ...]` cues for where to click. Content in the scripts is
drawn from real, already-published copy on the Golden Rise Bendigo site, trimmed for a short
example. Field labels and colour names match this site's own relabelled ACF choices exactly
(for example "Green" for the primary colour, "Angle >" for the chevron icon).
