# 03. Tabs Overview

**Summary:** A guided tour of the four tabs a row can have, Content, Intro, Grid & Display, and
Other Settings, what each governs, and which layouts show which tabs. **Example page:**
Training: Layout Tabs Overview (`training-layout-tabs`, draft, a single Stats row that happens
to carry all four tabs).

---

Open any row and you'll notice its fields are grouped into tabs across the top, up to four of
them: Content, Intro, Grid & Display, and Other Settings. This video is a quick tour of what each
one does.

I've set up Training: Layout Tabs Overview with a single Stats row, because it carries all four
tabs, so you can follow along on one row rather than jumping between pages.

[ON SCREEN: open the Stats row on the training page]

Content is always first, and it's unique to the layout, this is where a Stats row asks for its
numbers, or an Image Gallery asks for its images. Every layout has one.

Intro is next, and it's the same on every layout that has it: one content box for a heading and a
short lead-in above the row's main content. Not every layout gets one though, Full Width Image
and Columned Content leave it out by default, because those layouts usually open a page rather
than introduce a block sitting after something else.

Grid & Display is the one to watch, because it doesn't appear on every layout, only ones that
repeat, like Stats, Testimonials, Icon List, and Columned Content. It has two jobs: grid controls
how many items sit across the row at desktop, tablet, and mobile widths, and Display controls
whether those items sit on a plain background or inside a card with its own colour. A couple of
layouts, Call to Action and Enquiry Form, only get the card half, since they're a single block
rather than a repeating one, and Image Gallery and Logo Gallery only get the column half, since a
gallery has no card option.

And Other Settings rounds it out, on every row, no exceptions: section background colour, an
optional ID if you need to link to this section from a menu, and the padding we covered in the
Getting Started video.

So: Content is different every time, Intro and Other Settings are the same every time, and Grid &
Display depends on the layout. We'll go deeper on Grid & Display and on Buttons next.
