# 07. Row: Call to Action

**Summary:** Walkthrough of the Call to Action layout: block layout, button alignment, content,
its buttons repeater, and its card-only Grid & Display tab. **Example page:** Training: Call to
Action (`training-cta`, draft, one row with a single download button).

---

Call to Action is your closing nudge, a short message and a button, usually sitting near the
bottom of a page.

[ON SCREEN: open Training: Call to Action]

Content tab first. Block Layout picks Columns or Stacked: Columns puts your message on the left
and the button on the right, Stacked centres both, one above the other, better for a narrower
section. Button Alignment only appears once you've added a button, and controls whether multiple
buttons sit side by side or stack on top of each other.

Below that, Content is a short wysiwyg box, this layout is built for a single line or heading,
not a wall of text, then Buttons, the same repeater we covered in the Buttons video, add one or
more.

On this training example the row is set to Columns, with one button, "Download Information
Statement," styled as a solid Orange button with a download icon before the text.

Under Grid & Display, Call to Action only gets the Content Box half of that tab, since it's a
single block rather than a repeating grid. Switch Content Box to Card and it gets its own
background colour, on the training page it's set to Card with a Green background.

Other Settings is the usual: section background, ID, padding.

Simple layout, but it's doing a specific job, get the words and the button right and this is
often the highest-value section on the page.
