# 11. Row: Full Width Image

**Summary:** Walkthrough of the Full Width Image layout: the background image, overlay and
overlay colour, content, and buttons, typically a page's hero section. **Example page:**
Training: Full Width Image (`training-full-width-image`, draft).

---

Full Width Image is almost always your hero, a big image with a heading and button on top.

[ON SCREEN: open Training: Full Width Image]

Upload your Image, it spans the full width behind everything. Overlay, Gradient or Solid, is a
tint that keeps your text readable over a busy photo, turn it off if the image doesn't need it.
Overlay Colour supports transparency, on the training example it's a dark tint at about seventy
percent.

Content and Buttons work as usual, here there's one button, "Enquire Now."

No Grid & Display on this one, it's a single block. Other Settings as usual, though you'd rarely
touch the background colour since the image does that job.

This is the layout that sets the tone for a page.
