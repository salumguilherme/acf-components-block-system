# 01. Getting Started

**Summary:** How to create a page with the Page Builder plugin from scratch: setting the page
template, adding your first row, and the two settings that show up on almost every row, padding
and grid columns. **Example page:** Training: Getting Started (`training-getting-started`,
draft, Page Builder template, a Full Width Image row followed by a Content and Image row).

---

Hey team, quick look at how we build a page with our Page Builder plugin.

[ON SCREEN: Pages, Add New]

Create a page, give it a title, and under Page Attributes set the Template to "Page Builder."
The normal content editor disappears, that's expected, we build the page from rows below instead.

[ON SCREEN: scroll to the Page Content panel]

Scroll down to Page Content and click Add Row. Pick a layout from the list, and its fields
appear. Stack as many rows as you like, in any order.

I've built an example, Training: Getting Started, a hero followed by a content section, follow
along there.

Two things show up on almost every row. Padding, under Other Settings, controls the space above
and below a section, Default, Small, Large, or off. Grid only appears on layouts that repeat,
like Stats, and it sets how many items sit side by side, asked three times, once for desktop,
tablet, and mobile, so a row can drop from six columns to two without any extra work.

That's the model: rows, padding, grid. We'll cover each layout from here.
