# 04. Grid & Display

**Summary:** A closer look at the Grid & Display tab: grid columns across desktop, tablet, and
mobile, grid alignment, and the Content Box option that turns items into cards with their own
background colour. **Example page:** Training: Grid & Display (`training-grid-display`, draft,
three rows contrasting the full, columns-only, and card-only versions of this tab: Icon List,
Image Gallery, and Call to Action).

---

Closer look at Grid & Display, the tab people ask about most.

I've set up Training: Grid & Display with three rows to show every version of this tab.

[ON SCREEN: open the Icon List row's Grid & Display tab]

Icon List has the full set. Grid Layout (Columns) sets how many items sit across the row, asked
three times, desktop, tablet, mobile, so a six-column row can drop to two on a phone. Grid
Alignment is the text alignment inside each item.

Content Box is really a separate feature on the same tab. Leave it Seamless and items sit on the
plain background, switch to Card and each gets its own boxed background with a colour picker.

[ON SCREEN: switch to the Image Gallery row]

Image Gallery only has the columns half, no card, a gallery doesn't need one.

[ON SCREEN: switch to the CTA row]

Call to Action is the opposite, only Content Box, no columns, it's a single block.

Rule of thumb: layouts that repeat get columns, layouts that can be boxed get Content Box, some
get both, some get one.
