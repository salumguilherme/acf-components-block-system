# 17. Row: Sticky CTA

**Summary:** Walkthrough of the Sticky CTA layout: content and buttons, which breakpoints it
shows on, top or bottom positioning, the four trigger options, and the display count and period
that stop it becoming annoying. **Example page:** Training: Sticky CTA (`training-sticky-cta`,
draft, a bottom bar with a download button, triggered after thirty seconds).

---

Sticky CTA, the newest layout, a floating bar that slides in over the page rather than sitting
in the normal flow.

[ON SCREEN: open Training: Sticky CTA]

Content is your heading and message, an optional Image, and Buttons, same repeater as every
other layout.

Display on picks which screen sizes it shows on, Desktop, Tablet, Mobile, and Sticky on picks
Top or Bottom, whether it fixes to the top or floats along the bottom as visitors scroll.

Then the trigger, Show Call to action on: on page load, after scrolling a set number of pixels,
when a chosen element becomes visible, or after a number of seconds. Value of X takes the
matching number, or a CSS selector for "element visible."

[ON SCREEN: point to Value of X]

Display count and Display period cap how often a visitor sees it, zero shows every time, one or
more shows it that many times per session or per day. It always has a close button too.

On the training page it triggers after thirty seconds with a download button, set to always
show.

No Intro tab on this one, its heading lives in Content, and Grid & Display only offers Content
Alignment, it's a floating box, not a grid.
