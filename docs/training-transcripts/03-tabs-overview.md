# 03. Tabs Overview

**Summary:** A guided tour of the four tabs a row can have, Content, Intro, Grid & Display, and
Other Settings, what each governs, and which layouts show which tabs. **Example page:**
Training: Layout Tabs Overview (`training-layout-tabs`, draft, a single Stats row that happens
to carry all four tabs).

---

Every row's fields sit under up to four tabs: Content, Intro, Grid & Display, and Other Settings,
quick tour of what each does.

I've set up Training: Layout Tabs Overview with a Stats row, since it carries all four.

[ON SCREEN: open the Stats row]

Content is always first, and it's unique to the layout.

Intro is the same everywhere it appears, one heading and a short lead-in, though a few layouts
leave it out by default.

Grid & Display is the one to watch, it only shows up on layouts that repeat. It does two jobs:
grid sets how many items sit across the row at each breakpoint, and Display lets you box those
items as cards with their own colour. Some layouts only get one half of that, we'll cover it
properly next video.

Other Settings rounds it out on every row, no exceptions: background colour, an optional section
ID, and padding.

So: Content changes every time, Intro and Other Settings don't, and Grid & Display depends on the
layout.
