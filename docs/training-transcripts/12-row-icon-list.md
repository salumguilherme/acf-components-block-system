# 12. Row: Icon List

**Summary:** Walkthrough of the Icon List layout: the repeating icon and text pairs, how it
differs from Columned Content, and its full Grid & Display tab. **Example page:** Training: Icon
List (`training-icon-list`, draft, six sample features).

---

Icon List is for a set of short features or benefits, each with a small icon next to a line of
text, think of the kind of list you'd use for "what's included."

[ON SCREEN: open Training: Icon List]

In Content, the Icon List repeater, one row per item, an Icon upload and a line of Content, plain
text, not a full wysiwyg box, this layout is built for short, scannable lines rather than
paragraphs.

I've left six example items on the training page, things like low-maintenance living and
reverse-cycle heating, have a scroll through them.

One thing worth knowing, and it's on the front end rather than in the fields: this layout doesn't
lay out in strict rows and columns, it flows down and across like a newspaper column, so your
item count doesn't need to divide evenly into your column number, it'll still look balanced.

Grid & Display gets the full set, columns for desktop, tablet, mobile, alignment, and Content
Box. On the training page it's two columns on desktop, dropping to one on mobile, inside a white
card.

A quick way to tell this apart from Columned Content, which we covered earlier: Icon List is for
short, uniform items, icon plus one line, no buttons, no accordion. Columned Content is for
richer columns, headings, paragraphs, buttons. If what you're adding is a simple feature list,
this is the lighter, faster option.
