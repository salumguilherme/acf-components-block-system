# 12. Row: Icon List

**Summary:** Walkthrough of the Icon List layout: the repeating icon and text pairs, how it
differs from Columned Content, and its full Grid & Display tab. **Example page:** Training: Icon
List (`training-icon-list`, draft, six sample features).

---

Icon List, a set of short features, each with a small icon next to a line of text.

[ON SCREEN: open Training: Icon List]

One repeater: an Icon and a line of plain text per item, built for short, scannable lines.

I've left six examples on the training page, have a scroll through.

Worth knowing: it flows down and across like a newspaper column, so your item count doesn't need
to divide evenly into your columns.

Grid & Display gets the full set, here it's two columns dropping to one, inside a white card.

Quick distinction: Icon List is short, uniform items, no buttons, no accordion. Columned Content
is for richer columns. Simple feature list, this is the lighter option.
